Notes from Grok Bot 101

Some brief notes from the public Grok Bot Galaxy session “Grok Bot 101” (Day 1), as presented, including first-time setup. Not an exhaustive list or official guide.

  • Grok Bots are like a team of specialists you can delegate work to.
  • Name each Bot something that it's related to, so it has a starting point, like Slide Sonya.
  • In the Bot's Description, set the role and how it should work (for example, a Chief of Staff that always delegates rather than doing the work itself). Adapt their scope and persona to how you want to work. You can split them by expertise, function, project, etc. It's up to you.
  • They work in the cloud so work can continue when your computer is off.
  • Multiple Bots can work at the same time, and you can collaborate with them in real time. They can message each other, work together, and be tagged in chats.
  • You can open the shared computer to watch a Bot, take control, or teach it something.
  • If you train them on something, whether by typing to it or recording a task, they will learn from that and apply it next time.
  • Add multiple Bots into the same group chat so you are not hopping threads and can see them work together.
  • Voice dictation is available.

Controls:

  • In General settings, you can set permission rules with natural language. Add and set those rules before work starts.
  • There is a setting to never allow Grok Bot to execute on your computer.
